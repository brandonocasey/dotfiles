## Code, tests, and comments

Before writing, changing, or reviewing code, tests, scripts, configuration, or dependencies, read [code-quality.md](references/code-quality.md), [tests-and-lint.md](references/tests-and-lint.md), and [comments.md](references/comments.md) in one batch. Claude Code loads the same text as the `Code standards` rule on the first Read, Write, or Edit of a code file; when that rule is in context, skip these reads.

## Planning

Before writing a plan, read [planning.md](references/planning.md).

## Sources

[sources.md](references/sources.md) lists the research behind these rules, with links. Read it only when asked why a rule exists.
