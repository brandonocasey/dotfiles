- For a named symbol, find references with `rg -n '\bName\b'` and the definition with `rg -n '(fn|struct|enum|trait|type|const|class|interface) Name\b'` (`grep` only where `rg` is missing). Use `ast-grep` only when text matches would be ambiguous. Never run `cat` bare; use `rg`, `head`, `tail`, `sed -n`, or heredocs. Bash output over 6,000 characters is saved to a file and needs a second read: use the Read tool (`offset`/`limit` for a range) for longer reads and for files you will edit; Edit and Write reject files seen only through Bash.
