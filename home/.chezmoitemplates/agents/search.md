- For a named symbol, find references with `rg -n '\bName\b'` and the definition with `rg -n '(fn|struct|enum|trait|type|const|class|interface) Name\b'` (`grep` only where `rg` is missing). Use `ast-grep` only when text matches would be ambiguous. Never run `cat` bare; use `rg`, `head`, `tail`, `sed -n`, or heredocs. In Claude Code, view a file you will edit with the Read tool (`offset`/`limit` for a range); Edit and Write reject files seen only through Bash.
