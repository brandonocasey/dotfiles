- Status (2026-11-06): current. `home/.chezmoiscripts/any-linux/run_onchange_after_05-claude-install.sh` installs 2.1.296 (`bash -s 2.1.296`), `DISABLE_AUTOUPDATER=1` is exported in `1-env.fish` and `env.sh` (comment "Keep Claude Code on 2.1.296") and set in the `env` block of `claude-settings-modify.sh`. ## Change
Claude Code installs are pinned at 2.1.296. From 2.1.299 the managed security plugin (`cc-plugin-sec-default@builtin`) handles the `prompt.attachment` event, so the user's `context-lean` plugin hook for that event is skipped ("context-lean: prompt.attachment bypassed by cc-plugin-sec-default (tier user)"). Auto-update is off, `FORCE_AUTOUPDATE_PLUGINS=1` keeps plugin updates on, and the installer takes the version 2.1.296.

Note on dates: S dated this entry 2026-10-27, the date of the settings-template commit. The first pin was 2026-10-14.

## Results
The pin is a workaround, not a measured saving. What was measured:
- 2026-10-27 test (ac897b20, 3 runs, one per version, all exit 0): `bypassed` lines per run: 2.1.296 = 0, 2.1.308 = 1, 2.1.311 = 1. Hook-running marker lines ("rewrote it / left it out"): 2.1.296 = 6, 2.1.308 = 0, 2.1.311 = 0. Likely cause given in the report: the security plugin's event list includes `prompt.attachment` and `session.compact` in 2.1.308 and 2.1.311, but not in 2.1.296. Request tokens (input + cache creation + cache read) and cost: 2.1.296 13,223 ($0.0026464); 2.1.308 35,954 ($0.0071926); 2.1.311 36,078 ($0.0072424). One run per version, so these are single samples.
- On 2.1.296, context-lean cut the deferred tool list from 31,587 to 2,360 characters in a debug session (d1c44a2f).
- context-lean README (measured 2026-10-13, 2.1.296, `claude-opus-5-5`, two runs): last request 13,015-13,052 tokens with the mod against 37,336-37,406 without, about 24,300 fewer tokens per request.
- 2026-11-05 test on 2.1.318: the same test still shows `context-lean: prompt.attachment bypassed by cc-plugin-sec-default (tier user)`; on installed 2.1.296 it shows no bypass. Before that, the last real test was 2026-11-02 on 2.1.316, still bypassed. Not run on 2.1.317.
- Issue 102653 was still open with no maintainer reply on 2026-11-05. The last comment was Oct 23 and reported the same bypass on more hooks up to 2.1.309. The changelog for 2.1.302 to 2.1.311 contains no fix, and the 2.1.317 and 2.1.318 entries say nothing about `sec-default`, `prompt.attachment` or hook order.

Costs: Claude Code releases after 2.1.296 are not picked up on this machine. Other machines keep whatever version they have installed until `chezmoi apply` runs the pinned installer.

To unpin: remove `DISABLE_AUTOUPDATER` from `claude-settings-modify.sh` and the env files, and change the installer version, once the issue is fixed.
